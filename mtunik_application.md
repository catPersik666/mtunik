**[ НАЗВАНИЕ ПРОЕКТА ]**

“Анонимный Q&A для учеников лицея НИУ ВШЭ”

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

У лицеистов регулярно возникают вопросы, связанные с учёбой, внеучебной деятельностью и повседневной жизнью лицеистов. Однако не всегда существует удобный способ задать вопрос большому количеству учеников и получить на него ответ. На почту поддержки можно писать только по техническим вопросам, а делать рассылку всем через элжур для какого-либо незначительного вопроса непринято.

**[ ЦЕЛЕВАЯ АУДИТОРИЯ ]**

Целевая аудитория - ученики лицея НИУ ВШЭ, заинтересованные в получении ответов на интересующие их вопросы или в проведении какого-либо исследования.

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 

Сайт будет разрабатываться для десктопных устройств на новейших версиях frontend и css, и должен будет работать на основных браузерных движках:
* Google Chrome
* Microsoft edge
* Яндекс Браузер
* Opera

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Программный продукт будет предоставлять следующие возможности:
* Публикация вопросов.
* Просмотр вопросов других пользователей.
* Публикация ответов.
* Просмотр ответов других пользователей.
* Постановка никнейма.
* Указание класса обучения.

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ 2 программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

* Ответы mail: неподходящая для вопросов по лицею аудитория.
*	Элжур: допустимы только высокие по важности и срочности вопросы.
